# FourLab Academy

Portal de aulas e artigos científicos para prescritores (nutricionistas, médicos, educadores físicos). Acesso gratuito, liberado após aprovação do registro no conselho.

- **Front:** HTML + JS puro (padrão FourLab), supabase-js
- **Banco:** Supabase FourLab, tabelas `academy_*` (`supabase/001_academy_schema.sql`)
- **Vídeos:** Panda Video
- **Domínio:** academy.fourlabnutrition.com.br

`prototipo/` = protótipo navegável aprovado (dados de exemplo).
